# Logic_for_plugin

LogicTierPlugin: демо-плагин автоматической выдачи PvP-тиров (LT5 → HT1) для Paper 1.21.11.
Плагин полностью на русском: сообщения в чате оформлены через MiniMessage (`text/Text.java`),
у метрик боя есть подробная подсказка при наведении, справка `/tieradmin` кликабельная.

## Структура

- `plugin/` — исходники плагина (Gradle, Java 21)
  - `core` — чистая логика без Bukkit: Elo по режимам (сейчас включён только Sword; Crystal и Cart закомментированы до готовности их метрик), защита от повторных матчей,
    Skill Score, тир-движок (временный тир → фиксация), симулятор
  - `storage` — SQLite/MySQL через общий диалект, асинхронная запись в отдельном потоке
  - `tracker` — метрики боя без Bukkit: взмахи, попадания, урон нанесённый/полученный,
    точность, CPS (средний и пиковый), комбо (макс., средняя и медианная длина серии).
    О боях знает только через интерфейс `ActiveFights`
  - `fight` — жизненный цикл боя (старт, победа, отмена); реализует `ActiveFights`
  - `commands` — `/tier`, `/tieradmin`, `/duel` (заглушка)
  - `adapter` — слушатели Bukkit (`FightListener`, `MetricsListener`) и `ConfigLoader`
- `logic.md`, `logic_demo.md`, `realization.md` — проектные заметки

## Сборка

```bat
cd plugin
gradlew.bat test shadowJar
```

Готовый jar: `plugin/build/libs/LogicTierPlugin-1.0.0-SNAPSHOT.jar`. Скопировать его в `plugins/` сервера.

Симулятор формул без сервера (200 виртуальных игроков × 30 дней, плюс тест фарма):

```bat
gradlew.bat runSimulation
```

## Команды

| Команда | Что делает |
|---|---|
| `/tier [игрок]` | профиль: тир, место в топе, Elo, навык, винрейт, статистика за всё время (игрок может быть офлайн) |
| `/top [параметр] [страница]` | топы по рейтингу, навыку, точности, среднему комбо, лучшей серии, КПС, винрейту, победам; своё место в каждом |
| `/tieradmin fight <p1> <p2> [меч]` | начать рейтинговый бой; победа — убийство соперника |
| `/tieradmin simulate [игроков] [дней]` | прогнать симулятор прямо в игре |
| `/tieradmin set <игрок> <режим> <тир>` | выставить тир вручную |
| `/tieradmin reset <игрок> [режим]` | сбросить рейтинг |
| `/tieradmin metrics <игрок> [режим]` | метрики текущего боя и сводка по последним 20 боям |
| `/tieradmin info <игрок>`, `/tieradmin stats` | диагностика |
| `/tieradmin debug` | вкл/выкл лог каждого взмаха и удара в консоль сервера |

## Как считается рейтинг

- Победа над сильным даёт больше, поражение слабому стоит больше (ожидаемый результат Elo).
  Пример для игрока с Elo 1150: победа над 950 — +5, над 1150 — +11, над 1520 — +19;
  поражение от 950 — −16, от 1520 — −2.
- Бои с одним соперником за день: 100% → 70% → 50% → 30% → 10%, с 6-го боя — 0 (бой без рейтинга).

## Как выдаётся тир

Тир выдаётся, только когда выполнены все условия из `config.yml` → `tiers` сразу:
Elo, навык (точность + доля урона + комбо), уверенность в оценке и число боёв.
`/tier` показывает, каких условий не хватает до следующего тира.
В первые 10 боёв (калибровка) тир временный и оценивается по Elo и навыку.

## Как считается навык

Навык боя (0–100) = точность × 0.35 + доля урона × 0.35 + комбо × 0.30 (веса в `config.yml`).
Доля урона — нанесено / (нанесено + получено), комбо — лучшая серия относительно 8 ударов.
Первые 10 боёв (калибровка) Elo меняется в 1.5 раза быстрее, тир в это время временный.

## Выход из боя

- Вылетевший игрок может вернуться в течение 30 с, бой продолжится.
- Не вернулся — поражение. Победитель получает Elo как за обычную победу, но только если был хотя бы
  один удар или бой длился 15+ с (защита от накрутки через вход-выход).
- Ушедший теряет Elo × 1.0 / 1.5 / 2.0 за 1-й / 2-й / 3-й+ выход за 24 ч; после 3-го выхода — 10 мин без боёв.
- Skill Score при выходе не меняется ни у кого. Всё настраивается в `config.yml`, раздел `leave`.

## База данных

Таблицы `players`, `ratings` (игрок × режим), `matches`, `metrics` (игрок × матч).
По умолчанию SQLite (`plugins/LogicTierPlugin/tierplugin.db`); для MySQL — `database.type: mysql`
в `config.yml` (драйвер уже есть в Paper). Подробно, включая выбор хостинга: [docs/MYSQL.md](docs/MYSQL.md). Все запросы идут в отдельном потоке, главный поток сервера не блокируется.

## Запуск сервера

Положить `server.jar` (Paper 1.21.11) в корень и запустить `start.bat`. Нужна Java 21+.
